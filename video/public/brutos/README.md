# Biblioteca de planos recurso

154 planos, 275 segundos en total. Todos sin pista de audio.

Este es el índice de las tres carpetas juntas. Cada una tiene además su propio
README con el detalle de cómo salieron.

| Carpeta | Qué es | Resolución |
| --- | --- | --- |
| `brutos/` | Los 29 planos del reel original | 1920x1080 |
| `brutos/testimonios/` | De las piezas de testimonios en inglés y español | 1280x720 |
| `brutos/piezas-viejas/` | De cuatro piezas antiguas de la agencia | 1280x720 |

Se usan poniendo la ruta relativa a `brutos/`, porque `Planos` la compone sola:

```tsx
{ src: "piezas-viejas/habitacion-ventanal", dura: 1.8 }
{ src: "contraluz", dura: 1.4 }
```

Para un primer plano grande o un encuadre que recorte mucho, tira de los de
1080p. Los de 720p dan variedad, sobre todo de alojamiento y gastronomía.

## Ojo: seis tomas que están dos veces

Salieron de escanear los 154 planos unos contra otros. No se han borrado
porque los de la raíz los usa `ReelXacobeo.tsx` y quitarlos rompería la
composición, pero **no se deben coger las dos de un par en la misma pieza**:
es la misma toma con dos nombres.

| Plano | Es la misma toma que | Parecido |
| --- | --- | --- |
| `plaza` | `catedral-torres` | 0.97 |
| `terraza` | `testimonios/terraza-vistas` | 0.99 |
| `camino-abierto` | `testimonios/peregrino-solo` | 0.95 |
| `casa-rural` | `testimonios/casa-galeria` | 0.92 |
| `piernas` | `testimonios/botas-camino` | 0.88 |
| `fachada-moderna` | `testimonios/casona-moderna` | 0.88 |

El par `plaza` / `catedral-torres` está dentro de la misma carpeta, y el reel
del Xacobeo usa uno en el bloque 1 y el otro en el bloque 2, que son
contiguos. Eso es justo lo que avisa la regla 4 de `CLAUDE.md`. Queda
pendiente de decidir.

Para comprobar un plano nuevo contra toda la biblioteca:

```bash
python3 herramientas/scripts/duplicados.py bruto.mp4 12.4,15.8 18.2,20.1
```
